# GRD-10. Свёрточный слой и пулинг

**Автор:** Нина Ковалёва · **Занятие:** 10

Полносвязная сеть из GRD-8 смотрит на картинку как на 64 независимых числа: сдвинь цифру на один пиксель — и для модели это другой объект. Свёрточный слой устроен иначе: одно маленькое ядро проходит по всей картинке, и признак «здесь есть угол» ищется в каждом её месте. Это то, ради чего мы весь курс учились строить view и считать без циклов.

Заодно в проект приезжают **цифры 28×28**: 15 000 картинок из MNIST в `data/digits28.npz`. На них будет финальная модель курса.

И маленький рефакторинг: `MLP` умеет собирать только цепочку `Dense`/`ReLU`, а нам нужна произвольная последовательность слоёв.

## Что сделать

`gradient/data.py`:

- `DIGITS28` и `load_digits28(path=DIGITS28)` → `X` формы `(n, 1, 28, 28)` `float64` в [0, 1] (яркость / 255) и `y` `int64`. Ось 1 — канал: свёрточные слои ждут `(примеры, каналы, высота, ширина)`.

`gradient/layers.py`:

- класс `Sequential(layers)` — то, чем `MLP` был по сути: список слоёв, `params`, `grads`, `forward`, `backward`, `loss`, `predict`, `step`, `fit`, `train`/`eval`. `MLP` становится его наследником, который строит слои по списку размеров. Проверки GRD-8 и GRD-9 должны остаться зелёными.

`gradient/conv.py`:

- `windows(x, k)` — все окна `k×k` каждой карты: `(n, c, H, W)` → `(n, c, H-k+1, W-k+1, k, k)`, **без копирования** (`np.lib.stride_tricks.sliding_window_view`);
- класс `Conv2D(c_in, c_out, k, scale=0.1, seed=None, init="he")` — свёртка без дополнения:
  - `W` — `(c_out, c_in, k, k)`, `b` — `(c_out,)` нулями; веса берите из `init_weights` с `n_in = c_in * k * k` (именно столько чисел входит в один выход);
  - `forward` → `(n, c_out, H-k+1, W-k+1)`; смещение — своё на канал;
  - `backward(dY)`: `dW`, `db` и градиент по входу. Все три — через `einsum` по окнам, без единого цикла. Градиент по входу — «полная» свёртка `dY` с **развёрнутым на 180°** ядром: дополните `dY` нулями по `k-1` с каждой стороны и сверните с `W[:, :, ::-1, ::-1]`, поменяв местами оси каналов;
- класс `MaxPool2D(k=2)` — максимум по непересекающимся блокам (блоки вы уже делали на занятии 8); `backward` отправляет градиент только в те позиции, где был максимум; если максимум в блоке не единственный, делите градиент поровну между ними;
- класс `Flatten` — `(n, c, H, W)` → `(n, c·H·W)` и обратно в `backward`.

## Критерии готовности

- `make check-grd10` зелёный, прошлые тикеты не сломаны. **Сначала `make update`**: проверка GRD-8 обновилась под новую структуру слоёв.
- Все градиенты проходят `gradient_check`, включая градиент по входу свёртки — на нём ошибаются чаще всего.
- Сеть `Conv2D(1, 8, 3) → ReLU → MaxPool2D(2) → Flatten → Dense(1352, 10)` на 8000 картинок 28×28, `lr=0.1`, 5 эпох даёт не меньше 93 % (у меня 94,6 %).
