# GRD-14. Релиз 1.0

**Автор:** Нина Ковалёва · **Занятие:** 14 (рубеж)

Финальный релиз. Всё, что мы писали четырнадцать занятий, собирается в одну команду: обучить свёрточную сеть на цифрах 28×28, сохранить модель файлом, положить рядом картинки и отчёт. Именно это уедет на терминал сортировочной линии.

## Что сделать

`gradient/__init__.py` — `__version__ = "1.0.0"`.

`gradient/train.py`:

- `build_cnn(filters=16, seed=0)` — сеть `Conv2D(1, filters, 3) → ReLU → MaxPool2D(2) → Flatten → Dense(filters·13·13, 10)`;
- модель `"cnn"` в `MODELS`: учится на `load_digits28` оптимизатором `Adam(0.003)`, 20 эпох по умолчанию, батч 64;
- у `evaluate` появляются `epochs=None`, `save=None` (путь файла модели) и `figures=None` (каталог для картинок); в отчёт добавляется `history` — потери по эпохам;
- при `save` — модель сохраняется через GRD-11 с метаданными (`model`, `seed`, `accuracy`), при `figures` — сохраняются матрица ошибок и кривая обучения из GRD-13 (`confusion-<model>.png`, `curves-<model>.png`);
- CLI получает `--epochs`, `--save`, `--figures`.

`docs/release-1.0.md` — отчёт о релизе, пять разделов: `## Точность`, `## Сравнение моделей`, `## Где ошибается`, `## Ограничения`, `## Что дальше`.

## Критерии готовности

- `make check-grd14` зелёный **и все прошлые тикеты тоже**: релиз — это когда работает всё, от GRD-1.
- Свёрточная сеть даёт не меньше 96,5 % на отложенных 3000 картинках 28×28; цель — 97 % (у меня 97,1 % за 20 эпох, около полутора минут).
- Pull request, зелёные проверки, слияние и тег: `git tag v1.0.0 && git push --tags`.
- В отчёте — числа по всем трём моделям (kNN, softmax-регрессия, свёрточная сеть) на своих наборах, обе картинки и честный раздел «Ограничения»: чего ваша модель не умеет и где она сломается на настоящих конвертах.
