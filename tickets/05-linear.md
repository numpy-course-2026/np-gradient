# GRD-5. Линейная регрессия

**Автор:** Нина Ковалёва · **Занятие:** 5

Прежде чем учить нейросеть градиентным спуском, научимся решать задачу, у которой есть точное решение. Линейная регрессия — это наименьшие квадраты: найти коэффициенты, при которых сумма квадратов ошибок минимальна. Она же — эталон, с которым на занятии 6 будем сверять градиентный спуск.

Для сортировочного центра задача настоящая: оценить время обработки партии по её параметрам. Данные для неё соберём позже, а пока — синтетика, где правильный ответ известен.

## Что сделать

`gradient/linear.py`:

- `add_bias(X)` — столбец единиц слева: `(n, d)` → `(n, d + 1)`.
- класс `LinearRegression(method="lstsq", l2=0.0)`:
  - `method` — `"lstsq"` (через `np.linalg.lstsq`) или `"normal"` (нормальные уравнения через `np.linalg.solve`); другое значение и отрицательный `l2` — `ValueError` сразу в конструкторе;
  - `fit(X, y)` возвращает `self` и запоминает `coef_` — `(d,)` — и `intercept_` — `float`;
  - `predict(X)` → `X @ coef_ + intercept_`;
  - `l2 > 0` — гребневая регрессия: к сумме квадратов ошибок добавляется l2 · ‖coef_‖². **Свободный член не штрафуется**: сдвиг всех ответов на константу не должен менять `coef_`. Для `"normal"` — добавка к AᵀA; для `"lstsq"` — придумайте, какие строки дописать к A и нули — к y, чтобы обычные наименьшие квадраты минимизировали ровно эту сумму.

`gradient/metrics.py`: `mse(y_true, y_pred)` → средний квадрат ошибки, `float`.
