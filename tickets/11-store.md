# GRD-11. Сохранение и загрузка модели

**Автор:** Нина Ковалёва · **Занятие:** 11

Обученная сеть пока живёт только в памяти процесса: закрыли интерпретатор — начинайте сначала. Для сортировочного центра нужен файл, который можно положить на терминал линии, а через полгода прочитать и понять, что это за модель и на чём её учили.

Требование к формату одно, но жёсткое: **никакого pickle**. Файл модели приходит с чужой машины, а `pickle` при чтении выполняет код — этого достаточно, чтобы его не использовать. `np.load` умеет читать без pickle (`allow_pickle=False`); наша задача — сложить в файл только массивы и текст.

## Что сделать

`gradient/store.py`:

- `describe(net)` → список словарей: тип каждого слоя и параметры, нужные, чтобы создать такой же (`Dense` — размеры, `Conv2D` — каналы и размер ядра, `MaxPool2D` — `k`, `Dropout` — `p`, остальным хватит типа). Незнакомый слой — `ValueError`. Описание должно сериализоваться в JSON.
- `build(spec)` → `Sequential` по такому описанию.
- `save_model(path, net, dtype=np.float64, **meta)` — один `.npz`: параметры сети массивами и метаданные строкой JSON. В метаданные обязательно кладите версию «Градиента» (`gradient.__version__`), версию NumPy, тип сохранённых весов и описание архитектуры; всё, что передали в `**meta` (точность, набор данных, комментарий), — туда же. `dtype=np.float32` сохраняет веса половинным размером.
- `load_model(path)` → `(сеть, метаданные)`: собирает сеть по описанию, заполняет её веса из файла и возвращает словарь метаданных. Читайте с `allow_pickle=False`. Если форма параметра в файле не совпадает с формой в сети — `ValueError` с внятным сообщением: это самая частая ошибка при смене архитектуры.

Веса в сеть возвращайте в её собственном типе: файл в `float32` — не повод переводить в него модель.

## Критерии готовности

- `make check-grd11` зелёный, прошлые тикеты не сломаны.
- Предсказания загруженной модели совпадают с исходными **побитово** (при `float64`).
- В PR — размеры файла для `float64` и `float32` и максимальная разница предсказаний между ними на тестовой выборке. Стоит ли хранить веса в `float16`? Ответьте числами: посмотрите на шаг представимых чисел `float16` рядом с типичным значением веса.
