# GRD-7. Релиз 0.1

**Автор:** Нина Ковалёва · **Занятие:** 7 (рубеж)

Коллеги, пора показать работу сортировочному центру. У нас есть данные, разбиение, два классификатора и все нужные метрики — но пока это набор функций, которые знаете только вы. Релиз 0.1 — это одна команда, которую может запустить человек, не читавший код, и отчёт, который можно положить в письмо.

## Что сделать

`gradient/__init__.py` — `__version__ = "0.1.0"`.

`gradient/train.py`:

- `evaluate(model, seed=0, test_size=0.2)` — обучить модель `"knn"` (k = 3) или `"softmax"` (параметры GRD-6: `lr=0.5`, 50 эпох, батч 64, `seed` разбиения и обучения — один и тот же) на цифрах 8×8 и вернуть словарь, который целиком сериализуется в JSON:
  - `model`, `seed`, `n_train`, `n_test`;
  - `accuracy` — `float`;
  - `per_class` — список из 10 `float`: доля верных ответов по каждой цифре;
  - `confusion` — матрица ошибок 10×10 как список списков `int`;
  - `seconds` — время обучения и предсказания, `float`.
  Неизвестная модель — `ValueError`. Числа NumPy (`np.float64`, `np.int64`) JSON не примет — приведите их к `float` и `int`: подумайте, какой метод массива делает это сразу для всей матрицы.
- `python -m gradient.train --model knn|softmax --seed N --json ФАЙЛ` — печатает в одну-две строки точность, число тестовых примеров и худшую цифру; с `--json` пишет отчёт. Неизвестная модель — ненулевой код выхода (`argparse` с `choices` сделает это сам).

`docs/release-0.1.md` — описание релиза для сортировочного центра, три раздела:

- `## Точность` — обе модели, числа из отчётов;
- `## Где ошибается` — какие цифры путаются и почему, по вашему мнению (посмотрите на сами картинки через `as_images`);
- `## Что дальше` — что, по-вашему, нужно, чтобы обогнать kNN.
