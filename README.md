# «Градиент» — библиотека нейросетей на чистом NumPy

Сквозной проект курса «NumPy: от массива до нейросети». Вы пишете его с нуля, тикет за тикетом: от загрузки данных до многослойной и свёрточной сети, которая распознаёт рукописные цифры.

## Легенда

Вы — в ML-команде сортировочного центра. Центр хочет читать рукописные индексы на конвертах. Тимлид команды, Нина Ковалёва, решила начать не с PyTorch, а с маленькой собственной библиотеки на NumPy: на терминалах сортировочной линии нет места под большие фреймворки, а команде нужно понимать каждую строку модели. Тикеты пишет Нина.

## Правила проекта

1. **Ни одного Python-цикла по элементам.** Циклы по эпохам, батчам и слоям — можно. Проверки следят за этим в функциях, названных в тикетах.
2. **Никаких библиотек, кроме NumPy.** scikit-learn и PyTorch можно ставить себе для сравнения, но не импортировать в `gradient/`.
3. **Каждый тикет — pull request** в `main` с зелёными проверками. В описании PR — что сделано, как проверено и на что обратить внимание ревьюеру.

## Что где

```text
gradient/          ваш код: пакет библиотеки
data/              наборы данных (.npz) и их описание
tickets/           тикеты — по одному на занятие курса
checks/            проверки тикетов: checks/grdN/ — тесты тикета N; читайте, но не меняйте
```

## Рабочий цикл

```bash
uv sync               # один раз: Python 3.14, NumPy, pytest в .venv
make check            # проверки всех тикетов
make check-grd2       # один тикет
uv run python         # интерпретатор с вашим пакетом: from gradient.data import load_digits
```

Проверки гоняют все тикеты сразу, поэтому сначала баллов будет 0 из максимума — это нормально: курс идёт в своём темпе, и сумма показывает ваш прогресс. Если новый тикет сломал старый, это будет видно сразу.
